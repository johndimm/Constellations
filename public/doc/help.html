Help & Info

Constellations — an interactive graph for exploring lives, events, and their hidden connections.

What it does

Type any person, place, film, event, or idea. The app uses an LLM to classify it and expand it into a network of related entities. Each expansion reveals new connections — people who collaborated, events that intertwined, works that share creators. Click any node to expand it further. The graph grows outward from wherever you start.

The underlying model is a bipartite graph: the graph alternates between two kinds of nodes — individual people/creators (atomic) and the things they made or participated in (composite). All edges connect one of each kind; no person-to-person or work-to-work links are possible. This constraint makes the graph navigable.

Controls

Click Select a node or edge — shows details in sidebar Dbl-Click Open context menu (Expand, Expand More, Delete, Find Photo) Drag Move nodes; pins them in place Scroll Zoom in / out Arrow keys Move between events in Timeline mode

Modes

  • Explore — type a person or event, expand connections outward
  • Connect — type two terms, find a chain linking them through intermediaries
  • Timeline — shows composite nodes (events, films…) arranged chronologically
  • Compact — reduces node size for dense graphs
  • Text Only — suppresses images; faster on slow connections

Features

  • Browse People — filter Wikipedia's most-notable people by nationality, occupation, and century
  • Save / Load / Share — snapshot graphs by name; export and import as JSON
  • Edge evidence — click any edge to see a one-sentence justification with a source link
  • Expand More — forces fresh LLM expansion, avoiding already-fetched neighbors
  • LLM selector — choose DeepSeek, Gemini, OpenAI, or Anthropic; persists across sessions
  • URL parameters — ?q=term auto-starts explore; ?start=A&end=B auto-starts pathfinding
